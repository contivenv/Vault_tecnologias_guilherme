Em qualquer sistema operacional que você for usar o Syncthing, os passos serão os mesmos, pois a interface dele é executada diretamente em um navegador web, onde conseguiremos mexer em todas as configurações pela própria GUI dele. Com isso em mente, iremos para os passos abaixo.

##### 1. URL de acesso
Acesse o link http://127.0.0.1:8384/ no seu navegador para acessar o Syncthing. Podemos modificar a URL de acesso e personaliza-la também. Mostraremos mais no tópico de [[4. Personalização do Syncthing]].

##### 2. Aceite os termos ou recuse
Os termos de coleta de informações são completamente anônimos. Se quiser, você pode dar uma olhada no [Grafana](https://www.redhat.com/pt-br/topics/data-services/what-is-grafana) deles para poder ver mais [estatísticas](https://mon.syncthing.net/dashboards) do Syncthing.![[Captura de tela de 2025-10-09 16-39-31.png]]

##### 3. Configure uma senha
Clique em "ok" para continua ou em configurações para definir uma senha. É altamente recomendado configurar uma senha para sua proteção na transmissão de dados. Mais a frente iremos ver como configurar o Syncthing para acessar de qualquer rede, não somente da local, por esse motivo recomendamos uma senha.![[Pasted image 20251009170942.png]]
