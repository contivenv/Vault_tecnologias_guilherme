## Habilite o Active Directory no aplicativo Configurações no Windows 11

Em servidores Windows, os administradores podem [instalar o Active Directory](https://br.easeus.com/backup-recovery/praticas-recomendadas-para-backup-do-active-directory.html) usando o serviço Server Manager. O processo no Windows 11 é diferente. Para começar, navegue até o menu Iniciar e localize o bloco ‘ **Configurações** ’, que pode ser encontrado na seção ‘Aplicativos fixados’. Alternativamente, basta digitar ‘ **Configurações** ’ na barra de pesquisa do menu para acessá-lo rapidamente.

![ativar configuração no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/2_how_to_install_active_directory_settings.png)

Depois disso, na janela Configurações, clique na guia ‘ **Aplicativos** ’ presente na barra lateral esquerda para prosseguir.

![localizar aplicativos na configuração do Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/1_how_to_install_active_directory_start_menu.png)

Em seguida, na seção direita da janela, localize e clique no bloco ‘ **Recursos opcionais** ’ para continuar.

![recursos opcionais no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/3_how_to_install_active_directory_optional_feature.png)

Na tela seguinte, encontre o bloco ‘ **Adicionar um recurso opcional** ’ e selecione o botão ‘Exibir recursos’ situado na extremidade direita da tela. Esta ação abrirá uma nova janela na tela.

![visualizar recurso no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/4_how_to_install_active_directory_view_feature.png)

Posteriormente, na janela ‘ **Adicionar um recurso opcional** ’, digite ‘ **Active Directory** ’ na barra de pesquisa para encontrar a ferramenta desejada. Nos resultados da pesquisa, identifique 'RSAT: Active Directory Domain Services e Lightweight Directory Services e marque a caixa de seleção que acompanha. Por fim, clique no botão ‘Avançar’ localizado na parte inferior da janela de sobreposição para avançar.

![adicionar recurso no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/5_how_to_install_active_directory_add_feature.png)

Na próxima tela, clique no botão ‘ **Instalar** ’ presente na janela para iniciar a instalação.

![instalar novo recurso no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/6_how_to_install_active_directory_install_feature.png)

Pode demorar alguns minutos para instalar os serviços em seu sistema, aguarde até que o processo seja concluído.

![instalando novo recurso no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/7_how_to_install_active_directory_installing_progress.png)

Depois de instalado com sucesso, vá ao menu Iniciar e digite Ferramentas do Windows para pesquisá-lo. Em seguida, nos resultados da pesquisa, clique no bloco ‘ **Ferramentas do Windows** ’ para abri-lo.

Agora, na janela Ferramentas do Windows, localize e clique duas vezes no bloco ‘ **Usuários e Computadores do Active Directory** ’ para abrir e gerenciar os dispositivos conectados ao seu servidor.

![ferramentas do Windows no Windows 11](https://www.easeus.com/images/en/screenshot/todo-backup/business/8_how_to_install_active_directory.png)
