Instalação via Terminal (ProtonUp-Qt) 

1. **Instale o ProtonUp-Qt** (se não tiver):
```bash
flatpak install flathub net.davidotek.pupgui2
```
1. **Execute o ProtonUp-Qt** para baixar a versão desejada:
```bash
flatpak run net.davidotek.pupgui2
```

Na interface gráfica que abrir, selecione "Steam", clique em "Add version", escolha a versão mais recente do "GE-Proton" e clique em "Install"._

3. **Reinicie a Steam** para que a nova versão do Proton apareça nas propriedades dos jogos.
