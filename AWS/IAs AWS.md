##### Rekognition

Consegue extrair informações de imagens e vídeos. A cobrança é feito por chamadas. Mandamos a foto, identifica o rosto e acha a pessoa.

Podemos treinar o modelo para achar determinado informação.

Rekognition é excelente para identificação de rostos.
##### Textract

OSR com machine larning. Identificação de texto em algum documento. Informações pré processadas para nós.
##### Polly

TTS - texto para fala, em uma linguagem personalizada. Solução para texto informativo para pessoas ouvir, a fala do texto traduzido.
