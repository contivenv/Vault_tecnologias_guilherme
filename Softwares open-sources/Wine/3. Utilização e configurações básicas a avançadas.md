## Guia de Utilidades e Uso do Wine (Básico ao Avançado)

### 1. Uso Básico

#### Executando Aplicativos e Instaladores

- **Executáveis Padrão (`.exe`):** Para rodar um programa ou instalador do Windows, utilize o comando `wine` seguido do caminho do arquivo:
    
      
    
    Bash
    
    ```
    wine aplicativo.exe
    wine "C:\Program Files\Aplicativo\app.exe"
    wine ~/.wine/drive_c/Program\ Files/Aplicativo/app.exe
    ```
    
- **Instaladores MSI (`.msi`):** Pacotes de instalação no formato `.msi` devem ser executados através da ferramenta interna `msiexec`:
    
      
    
    Bash
    
    ```
    wine msiexec /i instalador.msi
    ```
    
- **Atalhos e Menu do Sistema:** Durante a instalação de um software, o Wine gera automaticamente ícones na área de trabalho e entradas no menu de aplicativos da sua distribuição Linux.
    
      
    

#### Estrutura do Ambiente (Prefixos e Drives)

- **O Prefixo Padrão (`~/.wine`):** Na primeira vez em que é executado, o Wine cria a pasta oculta `~/.wine` no seu diretório de usuário. Ela serve como um ambiente isolado do Windows para garantir a execução dos programas sem interferir no resto do Linux.
    
      
    
- **O Disco C Virtual (`drive_c`):** Localizado dentro de `~/.wine/drive_c`, essa pasta simula a estrutura tradicional de diretórios do Windows (`Program Files`, `Windows`, `system32`).
    
      
    
- **Mapeamento de Dispositivos (`dosdevices`):** O diretório `~/.wine/dosdevices` contém links simbólicos que traduzem as letras de unidade do Windows para os caminhos do Unix:
    
      
    - `c:` aponta para a pasta `~/.wine/drive_c`.
        
          
        
    - `z:` aponta para a raiz (`/`) do sistema Linux, permitindo que os programas do Windows enxerguem os seus arquivos de usuário do sistema hospedeiro.
        
          
        

#### Utilitários Gráficos Principais

- **`winecfg`:** Interface gráfica central para ajustar o sistema simulado. Permite definir a versão do Windows emulada (como Windows XP ou Windows 10), controlar drivers de som (como ALSA e OSS), ajustar o comportamento do mouse, configurar a resolução da tela e gerenciar bibliotecas (DLLs).
    
      
    
- **`winefile`:** Gerenciador de arquivos integrado com visual semelhante ao do Windows, útil para navegar nos drives virtuais e disparar executáveis diretamente.
    
      
    
- **`uninstaller`:** Ferramenta gráfica equivalente ao "Adicionar/Remover Programas" para desinstalar softwares do prefixo.
    
      
    
- **`wine control`:** Painel de controle para gerenciar e abrir applets específicos instalados por programas do Windows (como configurações do Internet Explorer ou QuickTime).
    
      
    

### 2. Uso Avançado

#### Variáveis de Ambiente

Você pode ajustar o comportamento do Wine diretamente no terminal definindo variáveis de ambiente antes da execução do comando:

  

|**Variável**|**Função / Descrição**|**Exemplo de Uso**|
|---|---|---|
|**`WINEPREFIX`**|Define um diretório customizado para criar um prefixo (ambiente isolado ou "garrafa") independente do `~/.wine` padrão.|`WINEPREFIX=~/.wine_jogo wine jogo.exe`|
|**`WINEARCH`**|Define a arquitetura do prefixo no momento da sua criação (`win32` para 32 bits ou `win64` para 64 bits/WoW64).|`WINEARCH=win32 WINEPREFIX=~/.wine32 winecfg`|
|**`WINEDLLOVERRIDES`**|Controla a ordem de preferência de carregamento entre DLLs nativas do Wine (_builtin_) e DLLs originais do Windows (_native_).|`WINEDLLOVERRIDES="comdlg32=n,b" wine app.exe`|
|**`WINEDEBUG`**|Ativa canais de rastreamento e depuração para investigar erros e comportamento de programas.|`WINEDEBUG=warn+heap,err+all wine app.exe`|

- **Detalhamento das DLLs (`WINEDLLOVERRIDES`):** O parâmetro `n` indica _Native_ (DLL original da Microsoft copiada para a pasta do programa ou para o `system32`) e `b` indica _Builtin_ (implementação nativa do próprio Wine). Usar `=""` desativa completamente uma DLL.
    
      
    
- **Canais de Debug (`WINEDEBUG`):** Permite filtrar mensagens por classe (`trace`, `fixme`, `warn`, `err`) e por canais específicos (como `heap`, `loaddll` ou `relay`). O canal `+relay`, por exemplo, registra cada chamada de função Win32 realizada pelo aplicativo.
    
      
    

#### Gerenciamento do Registro do Windows (`regedit`)

As configurações internas dos aplicativos e do sistema simulado ficam gravadas na estrutura do Registro do Windows, representada por arquivos de texto simples dentro do prefixo:

  

- **`system.reg`:** Contém as chaves relativas a `HKEY_LOCAL_MACHINE`.
    
      
    
- **`user.reg`:** Contém as chaves relativas a `HKEY_CURRENT_USER`.
    
      
    
- **`userdef.reg`:** Contém as configurações do usuário padrão (`HKEY_USERS\.Default`).
    
      
    

Para manipular a árvore do registro de forma segura, utilize a ferramenta gráfica executando `wine regedit` no terminal. As preferências avançadas do próprio Wine ficam em `HKEY_CURRENT_USER\Software\Wine`.

  

#### Controle de Processos em Segundo Plano (`wineserver`)

O `wineserver` é o processo daemon encarregado de fornecer ao Wine os serviços que o kernel do Windows forneceria no sistema original. Ele aceita parâmetros diretos no terminal para gerenciamento de processos:

  

- **`wineserver -k`:** Encerra imediatamente todos os processos e programas vinculados ao Wine (ideal para destravar aplicações congeladas).
    
      
    
- **`wineserver -p[n]`:** Torna o servidor persistente por `n` segundos (ou indefinidamente caso `n` seja omitido), impedindo que ele feche assim que um aplicativo termina e agilizando as inicializações subsequentes.
    
      
    
- **`wineserver -w`:** Faz com que uma nova chamada aguarde até que o `wineserver` atualmente ativo seja finalizado.
    
      
    

#### Integração de Hardware e Recursos do Sistema

- **Portas Seriais e Paralelas:** Podem ser mapeadas criando links simbólicos na pasta `~/.wine/dosdevices` que apontam para os dispositivos correspondentes do Linux:
    
      
    
    Bash
    
    ```
    ln -s /dev/ttyS0 ~/.wine/dosdevices/com1
    ln -s /dev/lp0 ~/.wine/dosdevices/lpt1
    ```
    
- **Compartilhamentos de Rede (UNC):** Requisições de rede no formato `\\servidor\pasta` são traduzidas para o diretório `~/.wine/dosdevices/unc/servidor/pasta`. Você pode vincular um ponto de montagem Samba ou NFS nesse local:
    
      
    
    Bash
    
    ```
    mkdir -p ~/.wine/dosdevices/unc/myserver/
    ln -s /mnt/smb/myserver/some ~/.wine/dosdevices/unc/myserver/some
    ```
    
- **Fontes do Sistema:** Adicionar novas fontes ao Wine é feito copiando os arquivos de fonte TrueType (`.ttf`) diretamente para o diretório `c:\windows\fonts` do prefixo.
    
      
    
- **Bancos de Dados ODBC:** O Wine conecta o arquivo `odbc32.dll` interno a gerenciadores Unix (como o `unixODBC`) definindo a variável de ambiente com o caminho da biblioteca: `export LIB_ODBC_DRIVER_MANAGER=/usr/lib/libodbc.so`.
    
      
    

#### Execução de Programas em Modo Console (CUI)

Para softwares de linha de comando sem interface gráfica, o Wine possui três modos de execução por meio do utilitário `wineconsole`:

  

- **Bare Streams:** Execução direta via `wine programa.exe`, mapeando a entrada/saída padrão diretamente no terminal Unix.
    
      
    
- **Backend USER:** Cria uma nova janela gráfica de terminal do Windows baseada na biblioteca USER32 (`wineconsole --backend=user programa.exe`).
    
      
    
- **Backend Curses:** Assume o controle do terminal Unix via biblioteca `ncurses` (`wineconsole --backend=curses programa.exe`), permitindo rodar aplicativos de console em tela cheia mesmo sem um ambiente gráfico (X11) ativo.
    
      
    

### 3. Dicas de Resolução de Problemas (Troubleshooting)

1. **Verificação de Versão:** Verifique se está utilizando uma versão atualizada executando `wine --version`.
    
      
    
2. **Identificação de DLLs Ausentes:** Rode o programa com a opção `WINEDEBUG=+loaddll wine programa.exe` para identificar exatamente quais bibliotecas estão falhando no carregamento.
    
      
    
3. **Ambiente Limpo:** Em caso de falhas recorrentes em instalações antigas, renomeie ou crie um novo `WINEPREFIX` limpo para descartar configurações corrompidas no registro.
    
      
    
4. **Instalação de Dependências com Winetricks:** Para softwares que exigem componentes adicionais do Windows (como pacotes redistribuíveis do Visual C++, DirectX ou bibliotecas .NET), utilize o script auxiliar `winetricks` para baixar e configurar as dependências automaticamente.
    
      
    
5. **Consulta à Base de Dados (AppDB):** Verifique a _Application Database_ (AppDB) no site oficial do WineHQ, onde a comunidade mantém registos de configurações, ajustes de registro e alternativas para rodar softwares específicos com sucesso.
