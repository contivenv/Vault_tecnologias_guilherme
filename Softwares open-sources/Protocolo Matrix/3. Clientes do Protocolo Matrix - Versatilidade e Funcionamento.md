## O Que São os Clientes Matrix?

No ecossistema do Matrix, os "Clientes" (Clients) são os aplicativos finais que os usuários utilizam para enviar mensagens de texto, compartilhar arquivos e realizar chamadas de voz e vídeo. Eles atuam como a interface de usuário do protocolo.

A arquitetura do Matrix quebra o paradigma do Ponto Único de Falha (SPOF). Em vez de depender de um servidor central de uma única empresa, a comunicação é distribuída através de servidores chamados _Homeservers_ (como o Synapse). A grande vantagem dessa arquitetura é a **Flexibilidade de Clientes**: assim como você pode acessar a mesma conta de e-mail utilizando o Outlook ou o Thunderbird, você pode usar clientes Matrix totalmente diferentes para acessar e gerenciar a sua mesma conta.

## Como Funciona a Comunicação por Trás dos Panos

Independentemente da interface visual, todos os clientes Matrix modernos funcionam seguindo os mesmos princípios de comunicação com os _Homeservers_:

- **Comunicação Baseada em API REST:** Os clientes enviam requisições HTTP REST diretamente para o servidor (geralmente usando a porta padrão 8008 no caso do Synapse).
    
- **Autenticação e Sessão:** Ao fazer login, o cliente envia as credenciais do usuário e recebe de volta um _token_ de acesso, que é usado para validar todas as requisições subsequentes.
    
- **Sincronização de Estado:** O envio e recebimento de mensagens baseia-se na sincronização. Quando o usuário envia uma mensagem, o servidor a processa como um "evento" imutável e, através do recurso de _sync_, atualiza o estado dessa sala para todos os outros clientes e usuários conectados.
    
- **Criptografia de Ponta-a-Ponta (E2EE):** A segurança do Matrix garante que os clientes gerenciem a criptografia usando mecanismos avançados (Olm e Megolm). Quando uma mensagem é criptografada no aplicativo, o _Homeserver_ atua apenas como um "carteiro cego" que armazena pacotes cifrados em seu banco de dados (como o PostgreSQL). As chaves necessárias para descriptografar os conteúdos ficam guardadas exclusivamente nos clientes (dispositivos) dos usuários.

## A Versatilidade do Ecossistema Open-Source

Como o Matrix é um padrão de código aberto mantido pela fundação sem fins lucrativos _Matrix.org_, qualquer aplicativo que suporte o protocolo pode ser considerado um cliente Matrix. Essa versatilidade permite o surgimento de clientes otimizados para necessidades extremamente específicas. Você não fica "preso" a um único aplicativo oficial.

Abaixo estão os principais clientes disponíveis e como eles atendem diferentes públicos:

### Clientes Completos e Modernos

- **Element (Web / Desktop / Mobile):** É o cliente mais conhecido, estabelecido e com a maior quantidade de funcionalidades no ecossistema. O Element possui foco em performance e usabilidade, suportando espaços (Spaces), _threads_, chamadas de voz e vídeo (via Jitsi e MatrixRTC), e é uma forte alternativa para equipes que usam Slack ou Teams.

- **Element X:** É a nova geração do cliente, desenhada primariamente para dispositivos móveis (iOS e Android). Ele se destaca por ser muito rápido, utilizando nativamente a tecnologia _Sliding Sync_ (que acelera drasticamente o carregamento de chats), além de autenticação OIDC e chamadas otimizadas nativas.

![[im-element-pt.jpg]]

### Interfaces Familiares e Focadas no Usuário Comum

- **Cinny:** Projetado para usuários que estão migrando do Discord e buscam um layout bastante familiar. Ele foca em apresentar uma interface simples, elegante e segura.

![[sddefault.jpg|700]]

- **FluffyChat:** Um cliente instantâneo com aparência adorável ("cute"), focado na simplicidade e usabilidade, especialmente para plataformas móveis. Apesar de simples, ainda oferece suporte a múltiplos perfis, espaços e recursos criptográficos.

![[unnamed1.png]]

### Clientes Nativos e Leves para Desktop / Web

- **Nheko:** Feito para usuários avançados e "tinkerers", é um cliente desktop nativo (escrito em C++20 e Qt) focado em ser leve e performático.

![[im.nheko 1.png]]

- **NeoChat:** Desenvolvido ativamente pela comunidade do KDE, é um cliente simples sob medida para a interface Plasma no Linux e Windows.
![[application.png|700]]
- **Fractal:** Escrito em Rust, é o mensageiro padrão para o ambiente de desktop GNOME, possuindo uma interface otimizada para a colaboração em grupos grandes.

![[Fractal-Matrix.png]]

- **Hydrogen Web:** Um projeto experimental focado em fornecer um cliente via navegador que seja incrivelmente leve, com boa compatibilidade abrangente de navegadores e funcionamento offline.

![[reXDIlXtderWuQKbpDlAoVyl.png]]
### Clientes para Terminal e Automações (CLI)

- **Matrix Commander:** Ferramenta de interface de linha de comando baseada em Python, sendo perfeita para criar tarefas agendadas (cron jobs), bots simplificados e para enviar ou receber textos via terminal.


- **Gomuks:** Outra opção minimalista de terminal, desenvolvida em linguagem Go, permitindo o envio de mensagens básicas em sistemas Linux, Windows ou macOS.
